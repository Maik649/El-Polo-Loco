## 🚀 Installation

### Voraussetzungen
- [Node.js](https://nodejs.org/) (v14 oder höher) oder entsprechende Runtime
- [Git](https://git-scm.com/)

### Schritt für Schritt

1. **Repository klonen:**
   ```bash
   git clone https://github.com/Maik649/El-Polo-Loco.git
   cd El-Polo-Loco
   ```

2. **Abhängigkeiten installieren:**
   ```bash
   npm install
   ```

3. **Spiel starten:**
   ```bash
   npm start
   ```

Das Spiel sollte sich dann in deinem Standard-Browser öffnen.

## 🎮 Verwendung

Nach dem Start des Spiels kannst du direkt mit dem Spielen beginnen. Das Spiel bietet verschiedene Level mit steigerndem Schwierigkeitsgrad.

## ⌨️ Steuerung

| Taste | Aktion |
|-------|--------|
| **Pfeiltasten** ↑ ↓ ← → | Spieler bewegen |
| **Leertaste** | Sprung / Aktion |
| **ESC** | Pause |
| **P** | Menü |

*(Bitte passe diese Steuerung an dein tatsächliches Spiel an)*
